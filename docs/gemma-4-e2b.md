# Gemma 4 E2B の端末内推論

LiteRT-LM 0.13.1 の CPU バックエンドで、端末に配置した
`gemma-4-E2B-it.litertlm` を読み込みます。クラウド API、AICore、定型応答への
フォールバックは使用しません。初回のモデル取得だけはHugging Faceから行い、取得後の推論は端末内で実行します。音声入力は別途 Android のオフライン音声認識を使用します。

## モデルの準備

モデル配布元:
https://huggingface.co/litert-community/gemma-4-E2B-it-litert-lm

Android 用の `gemma-4-E2B-it.litertlm` を取得してください。
Web / GPU / NPU 専用版ではありません。モデルは数 GB あるため、APK には含めません。
配布元の利用条件を確認し、オフライン利用前にモデルを端末へ配置します。

アプリ起動後に「モデルをダウンロード」を押すと、アプリが次のURLから取得して適切な場所へ配置します。

```text
https://huggingface.co/litert-community/gemma-4-E2B-it-litert-lm/resolve/main/gemma-4-E2B-it.litertlm
```

開発端末では、手動で次のように配置することもできます。

```sh
adb shell mkdir -p /sdcard/Android/data/com.abplus.botchchat/files/models
adb push gemma-4-E2B-it.litertlm /sdcard/Android/data/com.abplus.botchchat/files/models/gemma-4-E2B-it.litertlm
```

アプリの「ステータス再確認」を押すと読み込みが始まります。読み込み成功後のみ
送信可能になります。配置先は `Context.getExternalFilesDir("models")` です。
外部アプリ領域が利用できない端末では内部の `files/models` に切り替わります。
アプリをアンインストールするとモデルも削除されます。

## 実機確認

1. モデル未配置の状態で「利用不可」が表示され、送信できないこと。
2. モデル配置後に再確認し、Ready になること。
3. 機内モードで質問を送信し、実際の応答が順次表示されること。
4. アプリを閉じて開き直してもモデルを読み込めること。

モデルのロード・推論には十分な RAM と空き容量が必要です。
会話履歴は内部ストレージの `files/chat-history.json` に最大 1024 メッセージ
（ユーザー・アシスタント各 1 件）を保存し、古いものから削除します。起動時に
復元し、次回推論の `initialMessages` に直近の完了した会話を渡します。
履歴消去は保存ファイルと次回推論のコンテキストの両方に反映されます。

モデルの入出力上限は 8192 トークンです。入力は安全側の UTF-8 6000 バイト予算
（各会話往復にテンプレート用 64 バイトを加算）で直近の会話から選びます。
1024 件すべてが一度の推論に入るとは限りません。長すぎる入力はエラーを表示します。
生成途中は約 500 ms ごと、送受信完了時は直ちに原子的に保存します。
強制終了時は最後の保存まで復元し、中断された応答やエラーを次回のコンテキストに含めません。
ネイティブ KV キャッシュ自体は保存せず、保存履歴からコンテキストを再構成します。

## オフライン読み上げ

新しい Gemma の返答を受信しながら、句点・感嘆符・改行などの区切りごとに
Android TextToSpeech のキューへ追加し、日本語を順番に読み上げます。
区切りがない長文は約 120 文字で区切り、末尾の残りは受信完了時に読み上げます。ネットワーク不要かつインストール済みの音声だけを選択します。
モデルのダウンロードやオンライン音声への切り替えは行いません。対応する音声が
ない場合は画面に案内を表示するため、オフライン利用前に端末の音声合成設定で
日本語の音声データを準備してください。

上部のスピーカーボタンで読み上げをオン／オフできます。オフ、画面を離れる、
次の送信、履歴消去、マイクボタンによる音声入力開始で再生を停止します。
起動時に復元した履歴やエラー表示は読み上げません。生成に失敗・中断した場合は
読み上げキューも停止します（すでに再生済みの音声は取り消せません）。
長い返答は音声合成の入力上限に合わせて分割し、順番に再生します。

実機では機内モードにして、日本語の返答、長文、停止操作、画面を離れた場合、
アプリ再起動時に過去の返答を読み上げないことを確認してください。

読み上げへの受け渡しを画面更新より先に行います。生成中の画面更新は約 300 ms
間隔にまとめ、Markdown の解析・整形をバックグラウンドで行います。完了時には
全文を画面へ反映し、定期保存には未表示の受信済みテキストも含めます。
